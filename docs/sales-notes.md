# Notas comerciales para vender la demo NOVA Studio

## Qué negocios podrían comprar algo así

- Barberías premium o barriales que quieren verse más profesionales.
- Peluquerías con servicios de color, brushing, nutrición y eventos.
- Centros de estética con turnos por WhatsApp.
- Salones de uñas.
- Estudios boutique que mezclan belleza, barbería y cuidado personal.
- Negocios locales que dependen de Instagram pero necesitan una web ordenada.

## Qué mostrar primero en una reunión

1. Abrir la demo en mobile y mostrar el hero, el botón de WhatsApp y la claridad del primer impacto.
2. Bajar a servicios para remarcar precios, duración y categorías.
3. Tocar un servicio y mostrar cómo queda seleccionado en el simulador de turnos.
4. Completar profesional, día y horario para abrir WhatsApp con el mensaje listo.
5. Mostrar galería, antes/después, opiniones y promos para explicar confianza y conversión.
6. Cerrar con ubicación, horarios y FAQ para mostrar que el sitio resuelve dudas frecuentes.

## Funcionalidades de una versión inicial

- Página responsive completa.
- Servicios y precios administrados desde código.
- CTAs a WhatsApp.
- Galería y trabajos recientes con imágenes demo premium.
- Promos editables.
- Ubicación, horarios, redes y FAQ.
- SEO local básico.
- Deploy en hosting estático.

## Uso de imágenes demo

Esta versión usa imágenes demo/virtuales premium para que la presentación se sienta más real, editorial y vendible. Para un cliente real, estas imágenes se pueden reemplazar por fotos del local, trabajos realizados, equipo real, fachada, cabinas y productos. Ese reemplazo suele aumentar mucho la confianza porque convierte la web en una vidriera digital propia, no en un template genérico.

## Upgrades posibles

- Sistema de turnos real con disponibilidad por profesional.
- Panel admin para editar servicios, precios, horarios y promos.
- Recordatorios automáticos por WhatsApp o email.
- Pagos o señas online.
- Integración con Google Calendar.
- Blog o contenido SEO local.
- Fotos profesionales y dirección de arte.
- Mantenimiento mensual.
- Métricas de conversiones y eventos.
- Optimización de Google Business Profile.

## Cómo posicionarla

La venta no es solo "una página linda". Es una herramienta para que el negocio parezca más confiable, responda menos preguntas repetidas y convierta consultas de WhatsApp con más contexto.
